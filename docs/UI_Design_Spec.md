# MapproxyServer GUI 布局与交互设计规范（当前实现）

## 1. 目标与范围

本文档描述当前 `src/ui/gui_launcher.py` 与 `src/ui/gui_advancedsetting_manager.py` 的界面能力与交互行为，用于开发、测试与文档同步。

## 2. 主窗口布局

### 2.1 窗口尺寸策略

- 默认目标尺寸：`1256 x 740`（根据屏幕尺寸动态约束）
- 最小尺寸：`960 x 600`
- 主体容器：`Canvas + Scrollbar + scrollable_frame`
- 行权重：
  - Row 0：运行环境（固定）
  - Row 1：服务配置与控制（固定）
  - Row 2：运行状态（固定）
  - Row 3：运行日志&监控（可扩展）

### 2.2 模块分区

1. 运行环境
2. 服务配置与控制
3. 运行状态
4. 运行日志&监控（Notebook 多页签）

## 3. 主界面模块定义

### 3.1 运行环境（Row 0）

- 源码运行模式：
  - Python 解释器只读下拉框（自动扫描）
  - “刷新”按钮
- 打包运行模式（frozen）：
  - 内置解释器只读路径
  - “复制路径”按钮

### 3.2 服务配置与控制（Row 1）

- 第一行（配置）：
  - 端口输入框（1-65535）
  - 线程输入框（1-32）
  - 允许外部访问开关
  - Host 文本（基于开关自动显示）
  - “高级设置”按钮
  - “保存配置”按钮
- 第二行（控制）：
  - “启动服务”按钮
  - “停止服务”按钮
- 第三行（目录）：
  - 工作目录只读输入框
  - “打开目录”按钮

### 3.3 运行状态（Row 2）

- 状态圆点（灰/橙/绿/红）
- 状态文字（就绪、启动中、运行中、失败等）
- 服务地址只读输入框
- “复制”按钮
- “在浏览器打开”按钮

### 3.4 运行日志&监控（Row 3）

顶部工具栏：

- 日志级别筛选：`DEBUG / INFO / WARN / ERROR`
- 自动滚动开关
- 在主日志显示 Seed 信息开关
- 导出日志
- 清空日志

Notebook 页签：

- 系统日志（`ScrolledText`）
- Seed监控（`ScrolledText`）
- 图层列表（`Treeview`: Name/Format/Title，支持单击复制与 Hover 高亮）
- 切片进度（`SeedProgressCanvasView`，支持任务状态展示与打包按钮）

## 4. 高级设置面板

高级设置为单独 `Toplevel` 弹窗，由 `show_advanced_settings_dialog` 打开；服务运行中禁止打开。

### 4.1 面板结构

- 左侧菜单（Listbox）：
  - 性能与基础
  - 地图源与功能
- 右侧内容区随菜单切换
- 底部操作区：
  - 保存
  - 取消
  - 还原默认

### 4.2 性能与基础

- Seed 服务管理配置：
  - 并发进程数（Spinbox，1-16）
- 失败重试策略：
  - 启用自动重试
  - 最大重试次数（1-10）
  - 重试间隔秒数（1-60）
- 失败告警配置：
  - 启用失败告警

### 4.3 地图源与功能

- 地图源配置：
  - Global URL
  - China URL
- 地图功能配置：
  - 启用智能切换
  - 启用离线模式
  - 数据缓存根目录

### 4.4 弹窗体验

- 显示流程：先定位后淡入（alpha 动画）
- 提供异常兜底：动画失败时直接可见并可交互
- 取消时若有未保存更改，弹确认框

## 5. 状态与交互规则

### 5.1 服务状态联动

| 服务状态 | 配置控件 | 启动按钮 | 停止按钮 |
| :--- | :--- | :--- | :--- |
| Stopped | 可编辑 | 可用 | 禁用 |
| Starting | 禁用 | 禁用 | 可用 |
| Running | 禁用 | 禁用 | 可用 |

运行中会锁定配置，避免运行态修改造成配置与进程状态不一致。

### 5.2 输入与错误处理

- 端口与线程输入实时校验，非法值会触发 UI 反馈并限制保存
- 打开目录、启动服务、日志导出等操作均包含异常捕获与用户提示
- Seed 进度刷新使用调度节流，避免频繁重绘导致界面抖动

### 5.3 日志机制

- 系统日志与 Seed 日志分别缓存
- 日志级别切换时从内存缓冲重渲染
- 支持 `Ctrl+L` 快速滚动到底部

## 6. 配置持久化约束

- GUI 配置最终写入 `MapProxyLauncher/mapproxy_config/map_config.json`
- 旧文件 `config.json`、`advanced_settings.json` 仅兼容读取，不再写回
- `allow_external_access` 与端口等运行参数由 `ConfigManager` 统一管理

## 7. 术语与路径映射（迁移说明）

- 历史 `modules/ui/` 路径：对应当前 `src/ui/`
- 历史主配置分散存储：对应当前 `mapproxy_config/map_config.json`
- 历史根目录 `seed_status.json`：迁移到 `mapproxy_config/seed_status.json`

本文档仅描述当前已实现能力，不包含已移除的旧 Seed 独立面板与旧模块路径说明。
